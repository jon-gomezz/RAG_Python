# Lenguajes de programación

## Python

Python es un lenguaje de programación interpretado, de alto nivel y propósito
general. Destaca por su sintaxis clara y legible, lo que lo hace muy popular para
ciencia de datos, inteligencia artificial y desarrollo web.

## JavaScript

JavaScript es el lenguaje principal del desarrollo web en el navegador. Permite
crear páginas interactivas y, con Node.js, también se utiliza en el servidor.

## Rust

Rust es un lenguaje de programación centrado en el rendimiento y la seguridad de
memoria, sin necesidad de un recolector de basura. Se usa en sistemas y software
de bajo nivel donde la fiabilidad es crítica.
